# Ma Tournée 🚒

Application web mobile personnelle pour gérer une tournée de calendriers.

## Fonctionnalités V1

- Tableau de bord
- Maisons et personnes
- Statuts : à visiter, vendu, absent, refus
- Nombre de calendriers et montant
- Notes
- GPS
- Carte OpenStreetMap
- Statistiques
- Gestion d'année
- Export/import JSON
- Stockage local dans le navigateur
- PWA installable sur téléphone

## Utilisation

Le site peut être ouvert directement avec un serveur web.

Pour GitHub Pages :
1. Créer un dépôt GitHub.
2. Mettre tous les fichiers à la racine.
3. Activer GitHub Pages dans Settings > Pages.
4. Ouvrir l'adresse fournie sur iPhone/Android.
5. Sur iPhone : Safari > Partager > Ajouter à l'écran d'accueil.

## Important

Les données sont stockées localement dans le navigateur. Utiliser Exporter une sauvegarde régulièrement.

La carte utilise Leaflet + OpenStreetMap et nécessite une connexion pour charger les tuiles.
